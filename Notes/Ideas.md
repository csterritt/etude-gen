## Etude Generator

The main ideas here are:

- This is a web application, with full user authentication and session management
- Users must sign in to use the application
- I want to generate music for the piano
- The user should be able to select a number of parameters for the music generation
  - Number of measures
  - Time signature
  - Key
- The music should be generated from a list of:
  - Notes (e.g., C, D, E, C#, Bb) chosen from the selected key, but optionally including notes outside the key
  - Durations (e.g., 1/4, 1/2, 1, dotted half, dotted quarter, etc.)
  - Accents (e.g., staccato, legato)
  - Ties, slurs
  - Dynamics (e.g., p, f, mf, etc.)
  - Hand (left, right, both)
  - Whether to include jumps bigger than an octave
- The music should then be generated randomly from the list of notes, durations, accents, ties, slurs, dynamics, and hand(s) selected
  - The music should not be totally random:
    - There should be repeated phrases, arpeggios, and other patterns
    - The probability of an interval should be inversely proportional to the size of the interval, scaled so that an octave jump is three times less likely than a unison, with other intervals scaled accordingly
    - Note durations in a bar should sum properly to the number of beats in the bar
- The music should be stored internally in a presentation-independent way.
- The generated music should:
  - Have sheet music style images generated by lilypond (https://lilypond.org) using the current stable release
    - Notes played by the right hand should be in the treble clef (down to and including middle c), and have stems pointing up
    - Notes played by the left hand should be in the bass clef (up to and including middle c), and have stems pointing down
  - Have audio generated in a way that can be played by the browser when a button is clicked
- There should be a form with all the various parameters at the top of the page
- There should be a "Generate" button on the form that will generate the music and display it below the form
- The form should have the same values it had before the POST once the music is generated
- There should be a "Play" button that will only appear once music is generated, that will play the audio
