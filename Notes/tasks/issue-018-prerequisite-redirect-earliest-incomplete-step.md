# Tasks for #18: Direct requests for unavailable steps redirect to the earliest incomplete step

Parent issue: #18
Parent PRD: `Notes/PRD-etude-generator.md`

## Scope note

The canonical state-to-route table in the issue includes score-related rows
(current Piece with committed render, render failure, stale Piece). Those rows
depend on the Piece and render infrastructure built by Issues 20, 30, 31, and
32, which have not been implemented yet — the `EtudeParams` aggregate has no
Piece fields. This task list implements every row that is possible now: no
aggregate through review, plus the "stored values no longer validate" row. The
score rows will be added to the workflow service by those later issues when the
Piece infrastructure lands.
