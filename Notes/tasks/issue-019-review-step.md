# Tasks for #19: Review step showing the complete configuration

Parent issue: #19
Parent PRD: `Notes/PRD-etude-generator.md`

## Scope note

Issue 17 already delivered a stub `GET /etude/review` that renders the
read-only summary (`EtudeSummary` with `step='review'`) and a canonical
GET Back link. Issue 19 replaces that stub with the full review step:
the summary and Back link remain, and a real Generate form is added — a
`POST /etude/generate` form carrying the hidden workflow version with a
submit button, neither inert nor hidden. Until Issue 20 implements
generation, `POST /etude/generate` exists as a stub that redirects back
to review with a safe "not available yet" message; the form, its method,
its action, and its version field are asserted by this slice's tests.

`GET /etude/review` remains a safe, side-effect-free request. Review
completion is derived, never persisted: there is no stored review flag
anywhere in the aggregate, and the derived predicate is the generation
precondition. The predicate is computed by the same resolver Issue 18
builds (`src/lib/workflow-service.ts`), so this issue moves
`isReviewReachable` out of `src/lib/etude-invalidation.ts` and into the
workflow service, updating the one existing caller.
